# Binary Tree Project
## Overview
This folder contains a C++ implementation of a binary search tree (BST) with basic operations and traversal methods. The code demonstrates insertion, search, depth calculation, and tree traversals (inorder, preorder, postorder).

## Files
- `btree.hpp`: Interface and implementation for the binary tree class template.
- `main.cpp`: Example usage and demonstration of the binary tree operations.
- `a.out`: Compiled binary (may be generated after building).

## Features
- Insert elements into the binary tree
- Search for elements (`find`)
- Calculate depth of a node (`findDepth`)
- Inorder, preorder, and postorder traversals
- Copy constructor and destructor for proper memory management

## Compilation & Usage
To compile and run the binary tree example:
```
g++ -std=c++11 -o btree main.cpp
./btree
```
