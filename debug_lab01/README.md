# Debug Lab 01
## Overview
This folder contains a C++ program designed to practice debugging techniques. The code generates sets of random numbers with no duplicates per set. Students are tasked with identifying and fixing an infinite loop bug in the program.

## Files
- `bug1.cpp`: Source file containing the buggy random number generator.
- `README.md`: Documentation for the lab.

## Features
- Generates sets of random numbers without duplicates
- Demonstrates use of arrays and random number generation
- Practice identifying and fixing infinite loop bugs

## Compilation & Usage
To compile and run the debug lab program:
```
clang++ -Wall bug1.cpp -o buggy
./buggy
```
