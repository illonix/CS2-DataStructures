# Population Growth Debug Lab
## Overview
This folder contains a C++ program for simulating university population growth over several years. The code demonstrates input validation, dynamic memory allocation, and basic loop control for repeated calculations.

## Files
- `pop_growth.cpp`: Main source file for the population growth simulation.
- `Makefile`: Build instructions for compiling the program.
- `pop`: Compiled binary (generated after building).

## Features
- Input validation for population and growth rate
- Calculates population growth for 5 years
- Dynamic memory management
- Option to repeat calculations for different universities

## Compilation & Usage
To compile and run the population growth program:
```
make
./pop
```
