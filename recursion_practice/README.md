# Recursion Practice Lab
## Overview
This folder contains a C++ program demonstrating recursive and tail-recursive implementations of the Fibonacci sequence. The code allows users to compare standard recursion with tail recursion for generating Fibonacci numbers.

## Files
- `fibonacci.cpp`: Source file with both standard and tail-recursive Fibonacci functions.
- `a.out`: Compiled binary (may be generated after building).
- `README.md`: Documentation for the lab.

## Features
- Standard recursive Fibonacci implementation
- Tail-recursive Fibonacci implementation for improved efficiency
- User input for number of Fibonacci numbers to generate
- Prints both sequences for comparison

## Compilation & Usage
To compile and run the Fibonacci program:
```
g++ -std=c++11 -o fibonacci fibonacci.cpp
./fibonacci
```
