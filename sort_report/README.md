# Sort Report Lab
## Overview
This folder contains C++ programs for demonstrating and analyzing sorting algorithms. The code allows users to compare the performance and behavior of different sorting methods, and may include reporting features for timing and output.

## Files
- `sort_report.cpp`: Main source file for sorting and reporting.
- `a.out`: Compiled binary (may be generated after building).
- `README.md`: Documentation for the lab.

## Features
- Implements and compares multiple sorting algorithms
- Reports timing and performance statistics
- User input for array size and sorting method
- Prints sorted arrays and performance results

## Compilation & Usage
To compile and run the sort report program:
```
g++ -std=c++11 -o sort_report sort_report.cpp
./sort_report
```
